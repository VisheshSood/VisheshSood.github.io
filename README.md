## About

This repository contains the official website for **Innovative Gloves Co., Ltd.**, a Thailand-based manufacturer of premium disposable gloves.

The website showcases our company, product range, proprietary glove technologies, manufacturing capabilities, certifications, sustainability initiatives, global presence, and history of innovation.

Innovative Gloves was established in **2001** and is based in **Hat Yai, Songkhla, Thailand**.

## Getting Started

### Requirements

Make sure you have **Node.js** and **npm** installed.

Check with:

```bash
node --version
npm --version
```

### Install Dependencies

After cloning the repository, open the project folder and run:

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The local development website will be available at:

```text
http://localhost:4321
```

Astro will automatically refresh the website when project files are changed.

---

## Build for Production

Create the production build with:

```bash
npm run build
```

The finished production website will be generated inside:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```

## Project Structure

```text
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   └── styles/
├── astro.config.mjs
├── package.json
└── README.md
```

### `src/pages`

Contains the website pages and routes.

Astro automatically generates routes based on files located in this directory.

### `src/components`

Contains reusable website components such as:

- Navigation
- Footer
- Product cards
- Technology sections
- Buttons
- Content sections
- Shared UI elements

### `src/layouts`

Contains shared page layouts.

### `src/assets`

Contains images and other assets processed by Astro.

### `public`

Contains static files that are served directly.

## Development Guidelines

When updating the website:

- Keep reusable elements inside components.
- Maintain consistent styling throughout the site.
- Keep product names and specifications consistent.
- Optimize large images before adding them.
- Test layouts on desktop, tablet, and mobile.
- Avoid unnecessary client-side JavaScript.
- Keep Astro components focused and reusable.
- Check internal links after adding or moving pages.
- Run a production build before publishing major changes.

Before deployment:

```bash
npm run build
```

Make sure the project builds without errors.
